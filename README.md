# Karan Portfolio

A responsive, GitHub Pages-ready personal portfolio.

## Files
- `index.html` — main portfolio
- `style.css` — design and responsive layout
- `script.js` — mobile menu, scroll reveal and cursor glow
- `assets/profile.png` — supplied profile image
- `assets/Karan_Dilip_Ingale_Resume.pdf` — resume used by the Download Resume button

## Run locally
1. Keep the folder structure unchanged.
2. Double-click `index.html`, or open it with VS Code + Live Server.
3. The portfolio works without a backend.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. In GitHub: Settings → Pages → Deploy from branch → select `main` and `/root`.
4. Open the generated Pages URL.
